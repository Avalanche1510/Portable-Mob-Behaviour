# 热插拔怪物 AI 文档

PMB 是双端 Fabric 模组。服务端与所有客户端必须安装 PMB，且网络协议版本一致；显示版本无需完全相同。AI、伤害、Faction 数据和 `PmbAi` 配置由服务端决定；客户端只接收动画所需的少量视觉状态。

> **`26.10.4-1` 破坏性迁移**：请先备份世界。旧扁平 `PmbAi`、旧 `skillPriorities` 与技能形式的 `air_tracking` 不再读取。请转换 summon、数据包与实体数据。

```text
PmbAi:{skill:{active:{...},conditional:{...},priorities:{...}},pathfinding:{planner:{...},strategies:{...},air_tracking:{...},retreat:{...}}}
```
